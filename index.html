DirectX 11 Real-Time Renderer

The project uses DirectX 11 to create 3D objects in a scene. This can be used as a foundational tool to apply maths, physics or a game on top of it.

Currently it follows the 3D rendering pipeline and HLSL to utilise Phong Lighting techniques and it renders multiples objects using matricies

  • Language / API: C++, HLSL, ImGUI
  • Features implemented:
    1. Vertex and index buffers for a textured cube.
    2. Constant buffer containing World/View/Projection, Material, Light, camera position, and time; mapped/updated each frame,
    3. Basic lighting in pixel shader (ambient + diffuse + specular) and camera-aware specular.
    4. Basic input handling.
    5. ImGui integrated.
    6. Typeless depth texture.
    7. Depth-stencil view.
    8. Input layout for position,normals & texcoords.
    9. Rasterizer states (solid and wireframe) with runtime toggle.
    10. HLSL shader pipeline.
    11. (Anisotropic) sampler descriptor is configured and set for pixel shader usage.
  • Status and date: Work In Progress, Scoped for 30/11/2026
